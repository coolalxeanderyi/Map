🔑 GitHub 權杖

存檔需要一把只能改 Map 這個 repo 的權杖。權杖只會存在這台裝置的瀏覽器裡，不會上傳到任何地方。

怎麼拿權杖？（點我）
  1. 打開 github.com/settings/personal-access-tokens/new
  2. 名字隨便取（例如「美食後台」），到期日可以選久一點
  3. Repository access 選 Only select repositories → 選 Map
  4. Permissions → Repository permissions → Contents 選 Read and write
  5. 按 Generate token，把出現的那串字貼到下面
